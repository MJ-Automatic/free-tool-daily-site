5 paid apps you can replace for free

The full list from our post: what each tool replaces, what it does, how to start and the official link. All five are free to use.

rembg

Replaces remove.bg

Removes image backgrounds. Use it as a command line tool, a Python library, an HTTP server or a Docker container. MIT license.

How to start: Install it with Python (pip) or run the Docker image. The README has the exact commands.

github.com/danielgatis/rembg 25,000+ stars

Stirling PDF

Replaces Adobe Acrobat

50+ PDF tools: edit, merge, split, sign, redact, convert and more. Runs as a desktop app, in the browser, or on your own server, without sending documents to outside services.

How to start: Download the desktop app, or start it with a single Docker command (see the README).

github.com/Stirling-Tools/Stirling-PDF 94,000+ stars

Immich

Replaces paid photo storage

Self-hosted photo and video backup with mobile and web apps, automatic background backup, duplicate prevention and search by faces, objects and metadata.

How to start: Runs with Docker Compose on a home computer or a small server. Our VPS guide shows how to set up a server step by step.

github.com/immich-app/immich 116,000+ stars

Upscayl

Replaces paid AI upscalers

Free and open source AI image upscaler for Windows, macOS and Linux. It enlarges and enhances low-resolution images with AI models.

How to start: Download the installer for your system from the releases page on GitHub.

github.com/upscayl/upscayl 50,000+ stars

n8n

Replaces Zapier

Workflow automation and AI agents with a visual editor plus custom code, 1500+ integrations and 9,000+ templates. Fair-code license: free to self-host.

How to start: Self-host it with Docker. Our VPS guide has a working n8n example.

github.com/n8n-io/n8n 200,000+ stars
